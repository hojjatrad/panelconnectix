# تایید خودکار رسید بانکی - مستندات حرفه‌ای v6.8.16

## روش‌های پیاده‌سازی شده

### 1. مبلغ یکتا (Unique Amount) - پیشنهادی اصلی
**وضعیت:** فعال/غیرفعال از پنل: تنظیمات → تایید بانکی

**چطور کار می‌کند:**
- به جای مبلغ رند (290,000)، مبلغ یکتا (290,147) نمایش داده می‌شود
- عدد 100-999 تصادفی اضافه می‌شود
- در 30 دقیقه اخیر یکتا بودن چک می‌شود
- کاربر دقیقاً همین مبلغ را واریز می‌کند
- پیامک بانک حاوی 290,147 است → سیستم خودکار تشخیص می‌دهد

**امنیت:**
- حدس زدن مبلغ یکتا تقریباً غیرممکن
- انقضا 15 دقیقه‌ای
- شماره پیگیری تکراری چک می‌شود

### 2. پیامک بانک + اپ اندروید (SMS Forwarder)
**وضعیت:** فعال/غیرفعال از پنل

**معماری:**
```
بانک → SMS → گوشی اندروید (سیم‌کارت بانکی) → اپ Forwarder → https://yourdomain.com/api/bank-webhook?secret=xxx&amount=290147 → تایید خودکار
```

**تنظیم اپ:**
1. اپ SMS Forwarder را نصب کنید (یا APK اختصاصی ما)
2. فیلتر: فقط از شماره‌های بانک (200033, 200044, ...)
3. URL: `https://vpbotn.ir/api/bank-webhook?secret=YOUR_SECRET`
4. پارامترها: amount, sms, tracking, sender

**نمونه SMS بانک ملت:**
```
واریز 2,901,470 ریال به کارت 6037-****-1234
از کارت 6037-****-5678
پیگیری: 123456
```

**استخراج خودکار:** Regex مبلغ را از ریال به تومان تبدیل می‌کند

### 3. OCR رسید تصویری
**وضعیت:** فعال/غیرفعال (پیشنهاد: فقط کمک، نه تایید کامل)

**فرآیند:**
- کاربر عکس رسید را به ربات می‌فرستد
- OCR (Tesseract/Google Vision) متن را می‌خواند
- استخراج: مبلغ، پیگیری، تاریخ
- اگر مبلغ مطابقت داشت و تاریخ جدید بود → پیشنهاد تایید به ادمین
- ادمین با یک کلیک تایید می‌کند

**ضد تقلب:**
- شماره پیگیری تکراری چک
- تاریخ باید امروز باشد
- کیفیت تصویر چک

### 4. درگاه پرداخت (Zarinpal/IDPay)
**وضعیت:** فعال/غیرفعال - 100% خودکار و قانونی

**مزایا:**
- قانونی، بدون ریسک مسدودی کارت
- تایید آنی
- رسید جعلی غیرممکن

## تنظیمات پنل

مسیر: `تنظیمات → تایید خودکار بانکی` (`/settings/bank-verification`)

- فعالسازی کلی
- هر روش جداگانه ON/OFF
- شماره کارت و 4 رقم آخر
- شماره‌های فرستنده SMS بانک
- توکن امنیتی وب‌هوک
- انقضای مبلغ یکتا

## وب‌هوک

```
POST/GET https://yourdomain.com/api/bank-webhook?secret=xxx

Params:
- amount: 290147 (الزامی)
- sms: متن کامل پیامک (اختیاری ولی مفید)
- tracking: شماره پیگیری (اختیاری)
- card: 4 رقم آخر کارت (اختیاری)
- sender: شماره فرستنده SMS (اختیاری)

Response:
{
  "success": true,
  "matched_order": "ORD-ABC123",
  "auto_approved": true
}
```

## تست

در پنل تنظیمات، بخش "تست استخراج مبلغ از پیامک بانک" - متن پیامک را بچسبان و ببین مبلغ درست استخراج می‌شود یا نه.

## امنیت

1. فقط از شماره‌های بانک SMS قبول می‌شود (تنظیم در پنل)
2. secret قوی (32 کاراکتر)
3. مبلغ باید در 30 دقیقه اخیر سفارش داشته باشد
4. شماره پیگیری تکراری رد می‌شود
5. حداقل مبلغ 1000 تومان

## پیشنهاد نهایی

- **70% سفارشات:** درگاه زرین‌پال (خودکار 100%)
- **25% سفارشات:** مبلغ یکتا + SMS Forwarder (خودکار 90%)
- **5% سفارشات:** OCR + تایید دستی

این ترکیب 95% سفارشات را بدون دخالت شما تایید می‌کند.
