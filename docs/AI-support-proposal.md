# پیشنهاد افزودن هوش مصنوعی به پنل Connectix (با مدل‌های رایگان)

تاریخ: ۲۶ شهریور ۱۴۰۵ (۲۰۶-۹-۲۶) — محدودیت‌ها تا «سپتامبر ۲۰۲۶» راستی‌آزمایی شده‌اند

---

## ۱. چه چیزهایی می‌خواهیم

1. **پاسخ‌دهی هوش مصنوعی به تیکت‌های پشتیبانی** (بخش «تیکت‌ها» پنل — جداول فعلی `tickets` / `ticket_messages`)
2. **امکانات هوشمند دیگر در پنل** (دستیار برای نمایندگان، تولید changelog فارسی، طبقه‌بندی تیکت و…)
3. **هزینه صفر دلار** — فقط APIهای رایگان، بدون کارت اعتباری

## ۲. پیشنهاد-providerها (وضعیت رایگان در سپتامبر ۲۰۲۶)

| Provider | بهترین مدل رایگان | سقف روزانه رایگان | سرعت | فارسی | بدون کارت؟ |
|---|---|---|---|---|---|
| **Groq** ⭐ | Llama 3.3 70B | ۱٬000 درخواست + ۱۰۰K توکن/روز | بسیار سریع (۱-۲ ثانیه) | قابل قبول تا خوب | ✅ |
| **Groq** (حجم بالا) | Llama 3.1 8B | ۱۴۴۰۰ درخواست + ۵۰K توکن/روز | بسیار سریع | ضعیف‌تر (کلاسی‌فایر فقط) | ✅ |
| **Google Gemini** ⭐ | Gemini 2.5 Flash | ~۵۰ تا ۱۵۰۰ درخواست/روز (متغیر) | سریع | **بهترین فارسی** | ✅ |
| **OpenRouter** | مدل‌های `:free` (DeepSeek, Qwen3, Llama, Gemma…) | ۵۰ درخواست/روز (بدون اعتبار) / ۱٬000 با خرید ۱۰ دلار یک‌باره | متوسط | متفاوت | ✅ |
| ~~Cerebras~~ | — | **دیگر رایگان نیست** (تلاش ۵ دلاری با کارت، از جولای ۲۰۲۶) | — | — | ❌ |
| Mistral | — | ~۵۰۰K توکن/**ماه** | — | ضعیف | ✅ |

### ⚠️ نکتهٔ مهم دربارهٔ تغییرات سریع
لیمت‌های رایگان مدام عوض می‌شوند: Google در دسامبر ۲۰۲ سهمیهٔ رایگان Flash را چندین بار تغییر داد (یک‌بار حتی به ۲۰ درخواست/روز رسید!) و Cerebras که بهترین سقف رایگان را داشت، رایگان بودنش را جمع کرد. **به همین دلیل معماری باید «چند-provider با failover خودکار» باشد** — اگر یک‌جای سقفش تمام شود یا ببندند، پنل خودش برود سراغ بعدی. (بخش ۴)

### انتخاب نهایی پیشنهادی
- **اولویت ۱: Groq — `llama-3.3-70b-versatile`** → کارِ اصلی (تولید پاسخ تیکت) — سقف ۱۰۰۰/روز برای پنلی با ده تا چندصد تیکت در روز کاملاً کافی است.
- **اولویت ۲ (فوق‌العاده): Gemini 2.5 Flash** → وقتی جواب «باکی‌تی» باشد یا Groq پر شده باشد — بهترین کیفیت فارسی.
- **اولویت ۳ (حجم/نجات): OpenRouter `:free` یا Groq 8B** → فقط برای طبقه‌بندی سریع و fallback نهایی.
- **Llama 3.1 8B (Groq)** → فقط برای «طبقه‌بندی تیکت» (ارزان و ۱۴هزار تیکت/روز) چون فارسی‌اش ضعیف است و نباید جواب کاربر را بنویسد.

> ثبت‌نام همهٔ این‌ها رایگان و بدون کارت است: console.groq.com و aistudio.google.com (کلید از بخش API Keys).

## ۳. معماری «پشتیبانی هوشمند» — RAG ساده و عملی

### چرا «دیتابیس برداری» لازم نیست
پایگاه دانش یک پنل VPN حدود ۵۰ تا ۲۰۰ سؤالات/مستند فارسی است. برای این حجم، **جستجوی متن‌ساز (FULLTEXT MySQL) کافیه** — نه vector DB، نه embedding (که خودش سهمیهٔ رایگان دارد). ساده = قابل نگهداری.

### ۳.۱ جدول‌های جدید
```
ai_settings   : کلیدها، ترتیب providerها، mode، دما، فعال/غیرفعال
ai_knowledge  : id, title, keywords, content, category, active  ← پایگاه دانش
ai_logs       : id, ticket_id, stage(classify|draft|auto), provider, model,
                in_tokens, out_tokens, latency_ms, reply, accepted_by_admin
ai_auto_replies: id, ticket_id, user_msg_id, ai_reply, confidence, escalated
```

### ۳.۲ پایگاه دانش (مهم‌ترین قسمت!)
کیفیت جواب AI دقیقاً به این وابسته است. اسکیوپ پیشنهادی:
- روش اتصال (VLESS / VMESS / Reality / Trojan) + کد کانفیک
- رفع اشکال رایج: «پیام نمی‌رود»، «سرعت کم»، «اتصال قطع می‌شود»، «DNS»، «آپدیت برنامه»
- قیمت‌ها و پلن‌ها (از جدول پنل خوانده شود تا آپدیت بماند)
- قوانین، گارانتی، شرایط بازگشت وجه
- نسخه‌های جدید اپلیکیشن + changelog (از همان `app_versions` پنل)
- پاسخ‌های آمادهٔ فعلی شما (اگر دارید) — بهترین seed

### ۳.۳ سه حالت کار (ترتیب توصیه‌شده)

**حالت ۱ — «همراه هوشمند» (شروع با این، ریسک صفر)**
وقتی تیکت جدید می‌آید، AI یک **پیش‌نویس پاسخ + برچسب موضوع + اولویت** تولید می‌کند و به مدیر/نماینده نشان می‌دهد. شما یک کلیک «ارسال» یا ویرایش می‌کنید. کاربر هیچ‌وقت متوجه نمی‌شود مگر شما بخواهید.
→ این حالت از روز اول ارزش دارد: سرعت پاسخ شما ۳-۵ برابر می‌شود.

**حالت ۲ — «جواب خودکار + امداد انسانی» (بعد از ۱-۲ هفته دادهٔ log)**
- تیکت‌های **مطابقت‌دار با پایگاه دانش** (confidence بالا و موضوع رایج) → AI خودش جواب می‌دهد با لوگوی «🤖 دستیار هوشمند Connectix — این پاسخ خودکار است»
- تیکت‌های **پیش‌بینی‌ناپذیر / شکایت / درخواست پول / عصبانیت کاربر** → AI جواب نمی‌دهد، **تیکت را به سوپرگروه تلگرام می‌فرستد** (طبق قاعدهٔ دائمی شما: همهٔ گزارش‌ها به سوپرگروه) و منتظر انسانی می‌ماند.
- کاربر بعد از هر جواب می‌تواند 👍/👎 بزند → log برای بهبود.

**حالت ۳ — «تصاعد هوشمند»**
AI چند راند جواب می‌دهد؛ اگر ۲ راند پس از پاسخ کاربر مشکل حل نشد یا کاربر دوباره گفت «نه همان مشکل» → خودکار به انسانی واگذار + اعلان سوپرگروه.

### ۳.۴ Guardrails (نخست‌ازهمه در System Prompt)
- فقط با محتوای پایگاه دانش جواب بده؛ اگر ندانست بگوید «کارشناس ما به‌زودی پاسخ می‌دهد» (جواب ساختگی ممنوع)
- قیمت فقط از دادهٔ زندهٔ پنل؛ تخفیف/قول شخصی ممنوع
- هیچ اطلاعات سرور، کلید، IP داخلی و رمز را فاش نکند
- لحن: فارسی محترمانه، کوتاه، بدون تکرار جملات رباتیک
- اگر موضوع حقوقی/پول‌برداری/شکایت شدید بود → مستقیم امداد انسانی

## ۴. معماری فنی در پنل (PHP موجود)

### ۴.۱ فایل جدید: `core/AiService.php`
```php
class AiService {
    // زنجیرهٔ provider از تنظیمات: ['groq', 'gemini', 'openrouter']
    public function complete(string $system, string $user, array $opts): AiResult;
    // - cURL ساده، timeout 30s
    // - 429/5xx → بعدی در زنجیره (با backoff)
    // - شمارندهٔ روزانهٔ هر provider در DB (مستقل از ساعت سرور)
    // - log همهٔ صداها در ai_logs
}
```
ساختار OpenAI-compatible که Groq و OpenRouter مستقیم قبولش می‌کنند
(`https://api.groq.com/openai/v1/chat/completions`)؛ Gemini فقط endpoint خودش را دارد —
یک adapter کوچک ۳۰ خطی. کل کد: ~۳۰۰ خط.

### ۴.۲ اتصال به جریان تیکت (تغییرات کوچک)
- `TicketController::store()` → بعد از ساخت تیکت:
  1. کلاس‌فایر سریع (Groq 8B، ~۲ ثانیه): موضوع + اولویت + `is_money`/`is_complaint` flag
  2. اگر `mode >= draft`: تولید پیش‌نویس → ذخیره در `ai_auto_replies` (نشان داده می‌شود در `views/tickets/show.php`)
  3. اگر `mode >= auto` و flag امن: درج پاسخ خودکار + اعلان تلگرام به سوپرگروه «🤖 AI به تیکت #N پاسخ داد (conf ۰.۹۲)»
- `views/tickets/show.php` → کارت «پیش‌نویس هوشمند» با دکمه‌های **ارسال / ویرایش / رد** (کلیک‌ها در ai_logs ثبت می‌شوند = دیتای رایگان برای سنجش کیفیت)
- `views/tickets/create.php` (سمت کاربر) → پس از هر پاسخ AI: دکمهٔ «آیا این پاسخ کمکتان کرد؟»
- `cron/` → job شبانه: خلاصهٔ هوشمند تیکت‌های باز (تعداد، موضوعات داغ، موارد بی‌پاسخ ۲۴+ ساعت) → **سوپرگروه تلگرام**
- cron دیگر: پاک‌سازی logهای قدیمی + سنجش «نرخ پذیرش پیش‌نویس‌ها»

### ۴.۳ صفحه‌های پنل
- `settings/ai.php` — کلیدهای API (در `config.secrets.php` ذخیره، نه در DB عمومی)، ترتیب provider، mode (۰ خاموش / ۱ پیش‌نویس / ۲ خودکار)، دکمهٔ «آزمون اتصال» که با هر سه کلید تست زنده می‌زند
- `settings/knowledge.php` — CRUD پایگاه دانش + «تست جستجو» + import از متن/Markdown
- `settings/ai-dashboard.php` — نمودار: تیکت/روز، پاسخ خودکار، نرخ پذیرش، مصرف سهمیهٔ هر provider (برای دیدن «چقدر تا پر شدن فاصله مانده»)

### ۴.۴ امنیت و حریم
- **تطبیق داده:** قبل از ارسال به API، ایمیل/تلفن/IP/رمز/کلیدهای کانفیگ از متن تیکت حذف می‌شوند (regex + لیست فیلد)
- **حریم داده:** Gemini در سطح رایگان ممکن است داده را برای بهبود استفاده کند → برای محتوای حساس، ترتیب provider طوری باشد که Groq/OpenRouter (مدل‌های open-weight با سیاست no-training در پیکربندی) اولویت داشته باشند؛ در تنظیمات «حذف PII» همیشه روشن
- کلیدها فقط در `config.secrets.php` (همان الگوی فعلی پنل)، هرگز در Git
- Rate-limit سمت پنل: حداکثر N درخواست AI در دقیقه (جلوگیری از حمله/لحظهٔ ترافیک)

## ۶. برآورد مصرف رایگان (واقعی)

فرض: ۱۰ تیکت/روز (پنل متوسط)
- کلاس‌فایر: ۱۰۰ صدا (Groq 8B — از ۱۴٬۴۰۰ سهمیه، ۰.۷٪)
- پیش‌نویس/پاسخ: ۱۰۰-۳۰۰ صدا (Groq 70B — از ۱٬000 سهمیه، حداکثر ۳۰٪)
- گزارش روزانه + دستیار: ~۲۰ صدا
→ **حاشیهٔ امن ۳-۱۰ برابر تا سقف رایگان.** حتی پنل با ۵۰۰ تیکت/روز در رایگان می‌ماند؛ بعد از آن، Groq پولی ~۰.۵۹ دلار/میلیون توکن است (۵۰۰ تیکت/روز ≈ ۱-۲ دلار/ماه — هنوز ناچیز).

## ۷. نقشهٔ راه اجرا

**مرحلهٔ ۱ (یک نشست کاری):**
`AiService.php` + جدول‌ها + صفحهٔ تنظیمات + import پایگاه دانش (۳۰-۵۰ سؤالات) + **حالت پیش‌نویس (mode 1)** + دکمه‌های ارسال/رد در تیکت.
→ شما از همان روز اول استفاده می‌کنید؛ ریسک صفر.

**مرحلهٔ ۲ (بعد از ۱-۲ هفته log):**
جواب خودکار (mode 2) فقط برای دسته‌های «امن» + واگذار به انسانی + اعلان سوپرگروه + دکمهٔ رضایت کاربر.

**مرحلهٔ ۳:**
دستیار نماینده + خلاصهٔ هوشمند کرش + گزارش روزانهٔ هوشمند.

### کارهایی که شما باید انجام دهید (۱۰ دقیقه)
1. ثبت‌نام رایگان در **console.groq.com** → ساخت API Key
2. ثبت‌نام رایگان در **aistudio.google.com** → ساخت API Key (Google AI)
3. (اختیاری) **openrouter.ai** → API Key برای fallback
4. ۳۰-۵۰ پرسش‌وپاسخ رایج پشتیبانی را برایم بفرستید (یا اجازه بدهید از متن برنامه/قیمت‌های پنل خودم بنویسم و شما تأیید کنید)
5. کلیدها را در صفحهٔ تنظیمات AI پنل بچسبانید (خودتان) — هرگز در چت/تلگرام

## ۸. جمع‌بندی صادقانه

- **بله، با رایگان‌ها شدنی است** — برای حجم پنل شما، Groq+Gemini رایگان با چاشنی OpenRouter کافی است و «پاسخ خودکار ۲۴/۷ + پیش‌نویس برای انسانی» واقع‌بینانه است.
- **بزرگ‌ترین ریسک فنی:** تغییرات مکرر سقف رایگان → با معماری چند-provider و شمارندهٔ مصرف در پنل، هرگز «خاموش» نمی‌مانید؛ بدترین حالت: AI برای آن روز خاموش شود و همهٔ تیکت‌ها به حالت انسانی برگردند (graceful degradation).
- **بزرگ‌ترین ریسک کیفی:** جواب غلط خودکار به کاربر. با شروع از حالت پیش‌نویس + confidence + واگذار خودکار، این ریسک عملاً صفر می‌شود و با logها به‌تدریج شل‌تر می‌کنید.
- **کیفیت فارسی:** Llama 3.3 70B قابل قبول است ولی Gemini Flash بهتر است — بنابراین ترتیب پیش‌فرض پیشنهادی: **Groq (سرعت و سقف) → Gemini (کیفیت و فارسی) → OpenRouter (نجات)**.
