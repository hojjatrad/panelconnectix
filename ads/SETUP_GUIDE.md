### ✅ روش 1: پوشه promo (پیشنهادی - 2 دقیقه)

**ساده‌ترین و سریع‌ترین - همین الان آماده است!**

#### چی کار کردم:
فایل `promo/index.php` ساختم که یک لندینگ پیج کامل standalone هست و نیاز به لاگین نداره.

#### چطور بالا بیاری:

1. **فایل‌ها الان روی گیت هستن.** کافیه آپدیت کنی:
   ```
   https://vpbotn.ir/contax/auto_update_v571.php?key=CONNECTIX2026
   ```
   یا از پنل مدیریت > آپدیت > بررسی آپدیت

2. **بعد از آپدیت، صفحه با این آدرس‌ها باز می‌شه:**
   - `https://vpbotn.ir/contax/promo/`
   - `https://yourdomain.com/contax/promo/` (اگر دامنه اختصاصی داری)
   - `https://yourdomain.com/promo/` (اگر پنل رو در public_html نصب کردی)

3. **تست کن:**
   مرورگر رو باز کن و آدرس بالا رو بزن. باید صفحه تبلیغاتی رو ببینی!

#### چرا این روش خوبه؟
- ✅ نیاز به تنظیمات نداره
- ✅ چون پوشه `promo` وجود داره، `.htaccess` پنل اون رو مستقیم سرو می‌کنه (RewriteCond !-d)
- ✅ مستقل از لاگین پنل - همه می‌تونن ببینن
- ✅ SEO friendly
- ✅ می‌تونی لینکش رو تو بیو اینستا، کانال تلگرام، دیوار بذاری

#### شخصی‌سازی:
فایل `promo/index.php` رو باز کن و خط 5-7 رو ویرایش کن:

```php
$telegram_support = '@YourSupport'; // آیدی تلگرام خودت
$telegram_bot_demo = '@YourBrandBot'; // ربات دمو
```

### ✅ روش 2: دامنه اختصاصی / ساب‌دامین (حرفه‌ای)

**برای برندینگ قوی‌تر**

#### الف) ساب‌دامین:
مثلاً `https://reseller.yourdomain.com` یا `https://join.yourdomain.com`

**مراحل:**
1. در هاست > ساب‌دامین > بساز: `reseller`
2. پوشه `reseller` رو به `public_html/contax/promo` پوینت کن (یا محتویات promo رو کپی کن به پوشه ساب‌دامین)
3. حالا `https://reseller.yourdomain.com` همون صفحه تبلیغاتی رو نشون می‌ده

#### ب) دامنه جدا:
اگر دامنه جدا برای فروش داری (مثلاً `yourdomain.com` برای فروش و `panel.yourdomain.com` برای پنل)

1. محتویات `promo/` رو کپی کن به `public_html/` دامنه فروش
2. فایل `index.php` همون `promo/index.php` باشه

#### مزیت:
- ✅ خیلی حرفه‌ای‌تر: `https://yourdomain.com` صفحه فروش، `https://panel.yourdomain.com` پنل
- ✅ سئو بهتر
- ✅ اعتماد بیشتر مشتری

### ✅ روش 3: مسیر داخل پنل (با کنترلر)

**اگر می‌خوای آدرس مثل `https://yourdomain.com/reseller` بدون پوشه باشه**

#### مراحل:

1. فایل `controllers/PromoController.php` بساز:

```php
<?php
class PromoController {
    public function index() {
        // بدون نیاز به لاگین
        require __DIR__ . '/../views/promo/index.php';
    }
}
```

2. در `index.php` روتر اصلی، اضافه کن:

```php
if ($path === 'reseller' || $path === 'promo' || $path === 'join') {
    (new PromoController())->index();
    exit;
}
```

3. فایل `views/promo/index.php` همون محتوای `promo/index.php` باشه (بدون تگ <?php اول)

**مزیت:**
- ✅ آدرس تمیز: `/reseller`
- ✅ می‌تونی آمار بازدید رو تو دیتابیس ذخیره کنی
- ✅ می‌تونی فرم درخواست نمایندگی داخل خود پنل داشته باشی

## 📈 چطور تبلیغات رو پخش کنم؟

### 1. لینک‌ها رو کجا بذارم؟

- **بیو اینستاگرام:** `yourdomain.com` یا `vpbotn.ir/contax/promo`
- **کانال تلگرام:** پین کن + دکمه شیشه‌ای با لینک
- **دیوار / شیپور:** آدرس سایت رو بذار
- **واتساپ:** وضعیت + لینک
- **امضای ایمیل:** لینک

### 2. سئو:

فایل `promo/index.php` همین الان سئو شده:

- ✅ Title و Description
- ✅ OG Image (برای پیش‌نمایش تلگرام/واتساپ)
- ✅ کلمات کلیدی
- ✅ ساختار H1, H2
- ✅ سرعت بالا (Tailwind CDN)

برای بهتر شدن:

- یک فایل `sitemap.xml` بساز و آدرس promo رو اضافه کن
- در گوگل سرچ کنسول ثبت کن

### 3. آمار:

می‌تونی یک کد آمارگیر مثل:

- **Google Analytics**
- یا **یک فایل ساده لاگ** اضافه کنی به `promo/index.php`:

```php
file_put_contents(__DIR__.'/visits.log', date('Y-m-d H:i:s').' - '.$_SERVER['REMOTE_ADDR'].' - '.$_SERVER['HTTP_USER_AGENT']."\n", FILE_APPEND);
```
