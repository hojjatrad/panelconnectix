# Repository Memory Protocol
Recommended `engineering-memory/` files: PROJECT_OVERVIEW.md, ARCHITECTURE.md, DECISIONS.md, TEST_CATALOG.md, BUG_LEDGER.md, CHANGELOG.md, KNOWN_ISSUES.md. Keep concise and versioned. Validate against current code, label unknowns, add dates/commit/evidence, never store secrets or sensitive data. Memory persists only if files are saved and available in future sessions.
